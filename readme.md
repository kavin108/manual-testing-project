⭐ Project Title

Social Media Web Application – Manual Testing Project

📌 Project Description

This project is a manual testing project for a Social Media Web Application.
The main goal is to test important modules like Login, Sign-Up, Forgot Password, and Third-Party Login using different test scenarios.

Login Functionality
Sign-Up Functionality
Forgot Password
Third-Party Login (Google/Facebook)
Logout Functionality
UI Validation
